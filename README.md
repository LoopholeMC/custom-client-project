Custom Client Development Project
This repository serves as the public documentation and landing page for a private, personal development project.

My Custom Client is a private, local hobby project built for personal educational purposes and testing custom launcher configurations. It is a non-commercial, personal tool. It is not distributed to the public, contains no external branding, and does not violate the Minecraft Commercial Guidelines. It is also configured as a multi-tenant application with support for personal Microsoft/Xbox accounts. It utilizes standard public client authentication flows for secure Xbox Live login integration. It is developed by a solo independent developer.

For compliance or inquiry, please contact the developer via this GitHub profile.
